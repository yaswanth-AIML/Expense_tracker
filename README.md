The Expense Tracker is a Python‑based application designed to help users record, categorize, and analyze their daily spending. It provides a simple interface for managing both expenses and income, making budgeting easier and more transparent.

#Features
Add and manage expenses with category, amount, and date.

Track income alongside expenses for a complete financial view.

Store data in CSV files (expenses.csv, income.csv) for easy access and portability.

Analyze spending patterns and calculate totals.

Clean architecture for easy extension (e.g., database integration in future).

# Tech Stack
Language: Python

Data Storage: CSV files (expenses.csv, income.csv)
